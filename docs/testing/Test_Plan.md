# Preliminary Test Plan

## Objectives

Testing will verify that the AI Governance Risk and Approval Platform satisfies defined functional and non-functional requirements and that the MVP supports a complete governance workflow.

## Planned Test Categories

- Functional testing
- Role and access-control testing
- Input-validation testing
- Risk-classification rule testing
- Workflow state-transition testing
- Audit-history verification
- Usability evaluation
- Basic performance testing
- Security review

## Initial Success Criteria

- At least 90% of defined core functional test cases pass by Unit 7.
- All identified critical defects are resolved before final submission.
- Unauthorized users cannot perform restricted approval or administrative actions.
- Risk classifications can be traced to documented input factors and rules.
- Core records persist correctly through the end-to-end workflow.

## Test Data

Only synthetic or de-identified data will be used in the public capstone repository.
